# 사이트 설계도(PRD) — (사이트 이름 미정)

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
가게 홍보가 절실한 소상공인 사장님이 네이버플레이스로 가게를 알리는 방법을 보고, 체험단 문의를 남기게 하는 사이트

## 2. 손님
- 누가: 가게 홍보가 절실한 소상공인 사장님
- 어디서 알고 오나: 내가 직접 가게를 방문하거나, 네이버플레이스 등에서 검색해 찾은 가게 사장님께 내가 링크를 보내서 들어온다 (불특정 검색 유입보다 **링크를 받은 사장님**이 중심)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 비용 — 체험단을 하려면 얼마가 드는지
2. 효과 — 리뷰·저장·방문이 정말 늘어나는지
3. 진행 방법 — 내가 무엇을 하면 되고, 얼마나 걸리는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 체험단을 진행한 가게 사례
- 진행 가게의 전후 비교 (리뷰 수, 순위 등) — 실제 수치만 넣는다
- 체험단 운영 풀(참여 리뷰어)이 넉넉하다는 것 — 실제 규모를 받으면 넣는다
- 후기: 사장님 실제 후기 (받은 문장 그대로 넣는다. 지어내지 않는다)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 체험단 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 장)
1. 첫 화면 — 한 문장 + [체험단 문의하기] 버튼
2. 네이버플레이스로 가게 알리는 방법 — 사장님이 알아야 할 핵심을 쉽게 (체험단이 왜 도움이 되는지까지 이어지게)
3. 진행 방법 — 문의부터 리뷰가 올라오기까지의 순서
4. 비용 — 기본 10명 30만 원, VAT 별도
5. 사례와 전후 비교 — 진행한 가게, 리뷰 수·순위 변화 (실제 자료만)
6. 사장님 후기 (실제 후기만)
7. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 가게 이름 또는 네이버플레이스 링크
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 기본 10명 30만 원, VAT 별도
- 시간: (미정) — 진행 기간
- 위치: (해당 없음 / 미정)
- 연락 방법: 문의 폼 (그 외 전화·카카오톡 채널은 미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 온라인 결제 (기본값 — 결제는 상담 후 따로 안내)

## 10. 첫 화면 한 문장 후보
1. 손님이 찾는 건 네이버플레이스예요. 우리 가게가 먼저 보이게 해 드릴게요.
2. 리뷰가 쌓이면 손님이 옵니다. 체험단으로 첫 리뷰부터 시작하세요.
3. 홍보가 막막한 사장님, 네이버플레이스부터 같이 채워요.

## 11. 다음에 할 것
- 회원가입·로그인
- 체험단 신청(리뷰어용) 페이지, 홍보 방법 글 모음은 필요해지면 검토
- 사례·후기·운영 풀 규모 자료 모아서 채우기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 세련된 · 세리프 서체(Noto Serif KR) · 흰 바탕에 와인색 강조 하나 (2026-10-11 "따뜻한"에서 변경)
- 참고 디자인: https://dinnerqueen.net/ads — 그대로 베끼지 않고 구성과 분위기만 (큰 제목, 단계별 진행, 사례 카드, 빠른 문의 버튼)
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 유입 추적: UTM(utm_source·medium·campaign·term·content)을 30일 기억했다가 문의와 함께 저장. /admin에서 출처별 문의 수와 추적 링크 만들기
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
